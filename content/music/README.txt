KIZUNA BLADE — BUNDLED MUSIC
============================

Every MP3 in this folder is shipped inside the installer and analysed
automatically the first time the app runs on a machine.

Supported: .mp3 only

Notes
-----
* The filename becomes the track title, so name them how you want them to read
  in song select. "Song Name - Artist.mp3" works well.

* Each track is analysed once on first launch (a few seconds each) and the
  result is cached, so later launches are instant.

* Every file here is copied into the build. Ten 4-minute MP3s is roughly
  80-100 MB added to your installer, per platform.

* This folder is the complete playable library. The game does not include
  synthesized missions, a file picker, or a second personal music directory.

Licensing is on you
-------------------
Whatever you place in this folder is redistributed to everyone who downloads
the app. Commercial recordings need a licence for that; personal ownership of
a copy does not cover redistribution. Hosts act on DMCA notices, so an
unlicensed build will typically be taken down along with the download link.
